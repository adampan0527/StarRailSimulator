交付范围与验收

用固定的合成输入在不加载桌面界面的情况下跑完一场模拟战斗。首批覆盖行动值、拉条、能量、战技点、终结技插入、伤害、增减益和弱点击破，以及合成敌人的行为。公开资料用于建立规则模型，验收以锁定的合成规则与数据为准。

验收清单

  • ✓已通过：用固定的合成夹具跑完一场模拟战斗。以独立计算的预期值检查关键行动顺序、技能目标、战技点、能量、状态与击破时点；伤害按事先写明的数值精度和舍入规则核对。
  • ✓已通过：相同版本、初始条件、指令与种子产生相同事件顺序和结果；关闭详细日志时结果一致；非法指令不会留下部分结算。
  • ✓已通过：用 Release 构建跑首组基准，记录每秒完整模拟场次、单场耗时、线程数与峰值内存，作为后续比较基线。

验收证据： 完整合成夹具与手算结果、规则回归测试、Release 原始测量。

进展记录

  • 2026-11-15：完成首版公开机制调研，记录行动值、拉条、战技点、能量、终结技、伤害、状态与击破规则及可手算的合成用例。M02 验收统一采用离线合成夹具；Rust 核心和基准尚未实现。
  • 2026-11-15：将共享样例的版本值改为合成占位值，契约格式和测试输入的战斗条件保持一致；现有契约测试通过。
  • 2026-11-15：交付独立的 Rust 战斗核心、回放命令和首组基准。工作区 Rust 格式、Clippy 和测试通过，九项集成测试通过；同一完整合成夹具的 Release 单线程基线为关闭日志约 102 万场/秒、详细日志约 19.3 万场/秒。三项离线条件均有验证证据，M02 验收通过。
