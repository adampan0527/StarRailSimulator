交付范围与验收

把档案与核心接入桌面应用。用户可以编辑配置、组队、选敌、逐回合操作、查看结果和回放。

验收清单

  • ✓已通过：新用户无需修改文件，即可保存配装、选择目标、使用普攻和战技、插入终结技并完成 M02 的合成战斗。界面显示行动顺序、生命、韧性、能量和战技点。
  • ✓已通过：重启应用后能打开旧回放并定位关键事件；切换星魂或速度遗器后，以新会话展示可预期的差异，旧回放结果不变。
  • ✓已通过：从正式服「遗器」页录入库存，在「角色」保存星魂和穿戴，再从「组队」点击四个固定站位选择角色。属性和命途可组合筛选，保存并重启后空位与穿戴状态一致。
  • ✓已通过：使用已生成数据构建 Windows Release 后，空存档首次进入「角色」即可加载内置的正式服目录，无需手动导入。
  • ✓已通过：角色页可组合筛选遗器部位、套装、主词条和副词条。光锥弹窗的自选与光锥库标签均可按命途筛选，保存后重开保留光锥实例与叠影。
  • ✓已通过：角色页使用遗器图标卡片选择穿戴。四组筛选支持弹窗多选，打开时默认筛选所点槽位。当前穿戴和其他角色已穿戴的实例有状态标记，应用筛选后可继续选择遗器。
  • ✓已通过：「穿戴遗器」直接展示已装备遗器的本地图标、强化等级、主词条、副词条数值和可用的副词条强化次数。卡片和空位均可打开对应部位的选择弹窗。
  • ✓已通过：光锥录入、库存与装备选择展示本地图片、星星、命途和名称。五星使用金色卡片，四星使用紫色卡片，三星使用蓝色卡片。
  • ✓已通过：持有光锥在库存页和装备选择中按星级、实例等级、首次上线日期依次降序，同批按英文名 A–Z。光锥录入与自选光锥按首次上线版本、星级、上线批次依次降序，同批按英文名 A–Z。
  • ✓已通过：「角色」页卡片展示头像、名称、属性图标和命途图标，可组合使用名称搜索、属性筛选和命途筛选。角色列表和组队选人与光锥录入采用相同排序。打开卡片可查看对应形态的立绘并配置角色，返回后恢复筛选和卡片位置。
  • ✓已通过：主页从全局角色库选人并读取当前配装面板，可创建、命名、保存和切换多套配队，原已保存配队可继续使用。
  • ✓已通过：按名称、怪物 ID 或类别查找 4.7.0 可独立出场的敌人，逐站位设置等级并查看只读属性。
  • 未验收：在「编队」分别管理己方和敌方。重启 Windows 应用后复验多套敌方编队的站位、等级和战斗模拟选队名单。
  • ✓已通过：自选敌方提供五个可留空的固定站位。敌方卡片显示头像、名称、弱点及生命值、防御力和速度。宽窗口五个站位同排，窄窗口自动换行。
  • ✓已通过：使用 4.7 正式服账号和本机导出器，从「遗器导出」接收已穿戴与未穿戴遗器，复制文件链接并核对导出的库存和词条精度。
  • ✓已通过：从「遗器」页导入已保存的 JSON，显示实际库存。重复导入同一份快照不会重复新增实例。
  • ✓已通过：遗器导入保留游戏穿戴、词条强化次数和未解锁词条预览。已有库存可通过重新导入补齐信息，预览词条解锁前不计入属性。

  • 未验收：使用两个正式服 UID 验收首次导入、重复导入、切换和备注恢复。切换后角色配置、光锥、遗器和配队应各自对应所属账号。
  • ✓已通过：遗器卡片在副词条名称前展示离线图标，在数值右侧用彩色数字圆标展示已记录的 0–5 次强化。
  • ✓已通过：遗器卡片副词条单行排列，数值最多显示三位小数，相邻强化圆标之间留有间距。
  • ✓已通过：「遗器」页只展示五星遗器，每件一张带本地图标的卡片。卡片隐藏实例编号，可点击打开对应的编辑表单。
  • ✓已通过：五星遗器卡片展示副词条数值，库存支持翻页和跳页。主词条、副词条、套装与部位均可多选，四组取交集，副词条匹配门槛最多为已选项数。
  • ✓已通过：遗器库存和角色选装弹窗高亮结果卡片中命中筛选的已解锁副词条。清除筛选后恢复普通样式。
  • ✓已通过：「遗器」页的四种筛选各有多选弹窗，主词条、副词条和套装选项有离线图标，部位可按外圈、内圈整组或按单个部位勾选。主词条和副词条按固定优先级排列。
  • ✓已通过：「遗器」页套装筛选按首次上线版本倒序。同版本按套装 ID 升序。结果卡片先按强化等级降序，同等级沿用套装筛选顺序，排序覆盖所有页。
  • 未验收：按 design.md 审查配装页与战斗页；在 100% 和 150% Windows 显示缩放下检查布局、字体和关键路径，键盘可操作，加载、空白和失败状态可理解。
