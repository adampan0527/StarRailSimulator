交付范围与验收

用 Rust + Tauri 建立最小 Windows x64 应用。锁定工具链与依赖，搭好本地检查与测试入口。定义角色形态 ID 和战斗输入边界，用合成夹具验证契约。记录首发支持的 Windows 版本、参考机器、性能样本规模与计时口径。M01 仅验收离线工程底座。

验收清单

  • ✓已通过：在干净开发检出中按文档安装依赖，完成 Windows x64 构建，并启动窗口执行一次前端到 Rust 的调用。
  • ✓已通过：格式、lint、类型检查与已有测试可按文档运行。未接版本库或 CI 时保留本地执行记录；接入后让 Windows CI 执行相同检查。
  • ✓已通过：交付并验证带最小样例的共享契约，写清角色形态 ID、配置快照、合法指令、规则与数据版本字段。M02 和 M03 分别在接入时使用同一份样例；修改契约时同步更新两个调用方。
  • ✓已通过：固定包含四个角色形态和至少两个可区分敌方目标的离线合成样例。登记 M05–M07 使用的参考机器、样本定义和计时口径，并记录 M07 的验收阈值。

验收证据： 构建与启动记录、锁文件、共享契约、四人双目标合成样例及其校验值、基准约定。
