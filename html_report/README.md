## 更新 01 开发路线图

1. 在 [路线图源文档](../docs/roadmap.md) 更新对应里程碑。进度看板记录状态、依赖和验收记录；详情清单仅勾选已有验证的项目。新增进展在该里程碑的「验收证据」段后加 `#### 进展记录`，用普通列表记录日期、改动与验证结果；有验证产物时附相对于 `docs/roadmap.md` 的链接。同一里程碑状态不变的改动也要记录。
2. 在项目根目录运行下方命令。将更新的源文档和生成的 HTML 一起提交。检查模式会在内容未同步或生成目录留有过期里程碑页面时返回失败。

```powershell
node "html_report/01_开发路线图/build.mjs"
node "html_report/01_开发路线图/build.mjs" --check
```

双击该目录的 `index.html` 即可查看，无需本地服务器或联网。生成脚本只用 Node.js 内置模块。不要手改生成的 `index.html` 和 `milestones/*.html`；页面组装在 `components/`，样式在 `styles/`，素材在 `assets/`。查看仓库内的证据和规范时，应保留原有目录结构。

源文档保留既有看板表格和各节标题。里程碑使用 `M01` 这样的稳定 ID，详情标题使用 `### M01 · 名称` 并和看板一致；详情支持段落、四级标题、普通列表和验收清单，行内支持链接、粗体与代码。
