# M02 · 离线战斗核心与验收记录

实现标识：`star-rail-battle-core 0.1.0`，规则 `fixture.rules.v1`、数据 `fixture.data.v1`、随机算法 `fixture.rng.v1`。所有配置、敌人、战斗数值和基准输入均为合成数据。项目未接入 Git，本记录不过度解读为任何游戏内容覆盖声明。

## 可运行的接口

[Rust crate](../crates/battle-core/)独立于 Tauri、数据库、文件系统和网络。`Session::from_json` 解析 v1 输入；`PreparedBattle::new` 校验版本、全局单位 ID、初始资源和数据引用，冻结有效面板；`Battle::start` 按该快照开战。调用方使用 `legal_actions` 获取当前合法指令，用 `apply` 推进，用 `snapshot` 或 `events` 读取结果。`Battle::replay` 接受同一个准备输入和指令序列，允许在有效的前缀处停留。只有胜利、失败或回合上限才算运行结束。

```powershell
cargo run --locked -p star-rail-battle-core --example m02 -- replay
cargo run --locked -p star-rail-battle-core --example m02 -- replay contracts/battle-session.v1.example.json
cargo test --locked -p star-rail-battle-core
```

第一个命令输出完整合成战斗的状态和详细事件。第二个读取 [v1 共享样例](../contracts/battle-session.v1.example.json)，在第三个玩家决策点暂停。完整夹具沿用同一初始输入，使用[固定的八条指令](../crates/battle-core/fixtures/full-replay.commands.json)。其前两条和共享样例一致。

## 固定规则边界

- **调度：** 时间和速度均保留六位小数。行动条内部使用两者的乘积尺度，每次到达决策时点向上取整到百万分之一 AV，扣减至 0 截止。同刻时拉条到 0 的单位优先，其余按我方站位、当前波次敌方站位排序。单位普通行动重填行动条；施加到当前普通行动者的行动调整作用于下一条行动条。每场最多 256 个普通回合；新的波次保留我方资源、状态和行动条。
- **指令：** 普攻、战技只属于当前普通行动者；充能完成的任意存活队员可在玩家决策点插入终结技。终结技结算后保留普通行动者，不单独计回合。普通指令结算完会自动推进到下一玩家决策点；v1 不提供敌方自动动作之间的独立插入窗口。目标按实例 ID 查找；无需选目标的技能要求 `null`。全部校验通过后才提交，再递增决策编号。
- **资源与状态：** 战技点上限 5，普攻 +1、战技 -1；终结技先扣满能量，再结算技能及回能。普通回合用于状态计时；当前模型的护盾、易伤、加速按目标随后完成的回合到期，同类效果刷新。护盾吸收发生在防御、抗性和减伤之后，敌方受击回能在伤害后发给存活的受击者。
- **伤害与击破：** 比例用万分之一表示，伤害乘区保持整数分数，到每条伤害事件才向下取整。伤害事件同时记录计算值、护盾吸收和有效生命损失。对存活且匹配弱点的目标削韧，打空韧性的直接伤害仍使用 `0.9` 倍；随后独立结算击破伤害，并对存活目标延后 `25%` 基准行动条。目标下个普通回合开始时恢复韧性。直接伤害已击杀时不追加击破。
- **随机与日志：** 从同一 `u32` 种子初始化 SplitMix64，按动作和目标固定顺序抽样。支持随机选取存活队友或攻击首个存活队友。详细日志按发生顺序记录时间、波次、来源和目标；关闭日志时不分配事件列表，不改变结算和抽样。

当前数据表只有共享夹具的四种合成角色配置、额外的合成拉条辅助和两种合成敌人，校验支持的等级、行迹、装备以及队伍和波次规模。未建模的配置显式报错；逐属性击破附加状态、追击、多段技能、复杂敌方选敌和关卡轮次计时留给后续规则版本。[公开机制调研](m02-combat-mechanics.md)中更广的规则作为后续参考。

## 固定夹具的独立预期

丹恒、三月七、开拓者、娜塔莎的合成速度分别为 `125`、`100`、`92.3`、`80`。两敌均为 `100`，初始生命分别为 `1,000` 和 `950`。合成击破等级基值为 `100`。对敌防御倍率为 `500 / (500 + 500) = 0.5`；敌方打我方时为 `520 / (520 + 520) = 0.5`。

| AV | 行为 | 独立预期 |
| ---: | --- | --- |
| 80 | 丹恒普攻左目标 | `1,000 × 0.5 × 0.5 × 0.9 = 225`；韧性 `20 → 10`，战技点 `3 → 4`，能量 `50 → 70`。 |
| 100 | 三月七给丹恒护盾，两敌依次行动 | 战技点回到 `3`，护盾 `60`；左目标打站位第一的开拓者 `100`。固定种子第一抽选中丹恒，护盾吸收 `60`、生命减少 `40`、能量 `70 → 80`。 |
| 108.342362 | 开拓者普攻右目标 | `floor((900 + 100) × 1.1 × 0.5 × 0.5 × 0.9) = 247`；击破伤害 `100 × 2 × (0.5 + 10 / 40) × 0.5 = 75`。右目标生命 `628`，行动延后 `25 AV`。 |
| 125 | 娜塔莎普攻右目标 | `600 × 0.5 × 0.5 = 150`，右目标生命 `478`，战技点封顶 `5`。 |
| 160 | 丹恒战技击破左目标 | 直接伤害 `1,000 × 1 × 0.5 × 0.9 = 450`；击破伤害 `100 × 1.5 × (0.5 + 20 / 40) × 0.5 = 75`。左目标生命 `250`，受 `25%` 易伤；丹恒能量封顶 `100`，战技点 `5 → 4`。 |
| 200 | 丹恒先插终结技，三月七接着普攻 | 终结技 `1,000 × 1.8 × 0.5 × 1.25 = 1,125`，左目标失去剩余 `250` 生命；丹恒能量 `100 → 0 → 10 → 15`。三月七攻击右目标 `400 × 0.5 × 0.5 × 0.8 = 80`，战技点 `4 → 5`。 |
| 216.684724 | 开拓者战技击败右目标 | `1,100 × 1.2 × 0.5 = 660`，右目标失去剩余 `398` 生命。战技点 `5 → 4`、敌方累计有效生命损失 `1,950`，胜利。 |

左、右目标在 `100 AV` 行动后自然应在 `200 AV` 再动；受击破延后后应为 `225 AV`，所以完整夹具不会执行第二轮敌方动作。另一条回归路径主动放弃终结技并保留目标，断言 `225 AV` 恢复韧性且易伤在目标回合结束时到期。
