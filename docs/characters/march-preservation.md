# 三月七（存护）4.7.0 战斗规则

形态 ID 为 `march_7th.preservation`，原始角色 ID 为 `1001`。80 级固定 DPR 使用档案解出的有效技能等级。四项技能的 55 行等级参数与锁定版本原始 `AvatarSkillConfig` 中的 `ParamList` 逐行核对。回能与削韧取同表的 `SPBase` 和 `StanceDamageDisplay`，与原始韧性显示单位保持 1:3 的换算。[M03 源修订与校验](../m03-profiles.md) · [4.7.0 原始数据对照](https://hsr.gachabase.net/characters/1001/march-7th/release)

| 记录 | 目标与资源 | 规则 |
| --- | --- | --- |
| 普攻 `skill.100101` | 敌方单体，20 能量，+1 战技点，10 削韧 | 攻击力倍率的冰伤。 |
| 战技 `skill.100102` | 我方单体，30 能量，−1 战技点 | 盾量由三月七总防御乘技能倍率后加固定值并向下取整。持续目标的三个普通回合。行迹 `trace.1001101` 先解除一个负面状态，`trace.1001102` 延长一回合。 |
| 终结技 `skill.100103` | 敌方全体，消耗 120 能量，结算回 5，每目标 20 削韧 | 先结算全体冰伤，再独立判定各个存活目标。一回合冻结的基础概率为 50%，行迹 `trace.1001103` 增加到 65%。冻结在目标回合开始结算独立冰伤，跳过该次行动。 |
| 天赋 `skill.100104` | 攻击者，每次回复 10 能量，10 削韧 | 受击前持有任意护盾的我方角色触发对攻击者的冰属性反击。护盾可在该次命中耗尽。次数随三月七的自身回合重置，基础两次。 |

E1 按终结技成功施加的技能冻结目标数额外回复 6 能量。E2 开战时给最低生命比例的存活队友三回合护盾，容量为总防御的 24% 加 320。等比例时按固定队伍站位选取。E3、E5 由档案解析技能等级。E4 增加一次反击额度，将 30% 总防御加进同一反击伤害基数。E6 在战技盾存在时，于受保护角色回合开始按其自身最大生命的 4% 加 106 治疗。E2 开场盾不触发 E6。[官方图鉴](https://wiki.hoyolab.com/pc/hsr/entry/7?crawler=Googlebot&lang=)

固定靶机不会攻击，自动固定打法也不选纯防御战技。盾量、净化、治疗及反击使用手动指令和离线有限敌人测试。战技盾的仇恨倍率与秘技入场未在该场景建模。冰击破与技能冻结同时施加时，共用规则保留最近施加的冻结；优先级、E1 回能倍率、E6 治疗加成和反击时序等待正式服逐事件复核。

用 `cargo test -p star-rail-battle-core --locked --offline march_preservation` 复验普攻资源、净化与盾时长、E2 目标、E6 生效条件、终结技冻结和附伤、E1 回能、E4 反击次数与计算、可复现回放及固定靶场。[回归用例](../../crates/battle-core/src/battle/official/march_preservation/tests.rs)
