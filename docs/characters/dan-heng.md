# 丹恒（巡猎）4.7.0 战斗规则

适用形态为 `dan_heng.hunt`，正式规则使用 4.7.0 的 80 级固定 DPR 靶场。伤害倍率、有效技能等级、基础回能与削韧总值按本地锁定目录和同版原始表核对。角色源 ID 为 `1002`，基础技能 ID 为 `100201` 至 `100204`。行迹 `1002101` 至 `1002103` 和星魂 `100201` 至 `100206` 分别来自原始行迹表和星魂表。[数据版本与重建](../m03-profiles.md#数据来源与离线重建) · [4.7.0 发布数据对账](https://hsr.gachabase.net/characters/1002/dan-heng/release)

| 动作 | 目标与基础资源 | 结算 |
| --- | --- | --- |
| 普攻 | 单体风伤，20 能量，10 韧性，生成 1 战技点 | 两段分配 45%／55%。目标减速时，解锁 A6 的丹恒增加 40% 普攻增伤。 |
| 战技 | 单体风伤，30 能量，20 韧性，消耗 1 战技点 | 四段分配 30%／15%／15%／40%。每段独立暴击，暴击时以技能参数的基础概率施加减速，按目标两个回合计时。同源同强度减速重新施加刷新，E6 把减速从 12% 提高到 20%。 |
| 终结技 | 单体风伤，消耗 100 能量，攻击后回 5，30 韧性 | 减速目标使用基础倍率加技能的条件倍率。E4 终结技击杀后使丹恒立即行动。 |
| 天赋 | 成为我方技能目标时生效 | 风抗穿透覆盖下一次攻击的各段直接伤害，随后开始两回合冷却。E2 将冷却缩短至一回合。 |

E1 对生命值至少一半的目标提高 12% 暴击率，逐段判定。E3 和 E5 提升的等级已由档案层提供。A4 每次完成主动攻击进行一次 50% 固定概率判定，成功后提高自身 20% 速度，持续两个回合。普攻使用整数韧性 5／5，保留 10 点总削韧。两种动作的段数和命中比例用于当前估算，逐段韧性量及事件顺序仍待 4.7.0 客户端逐帧对照。

固定靶机始终存活且不会主动攻击。E4 在可击杀的离线夹具内验证，A2 的低生命降仇恨等待真实敌方攻击规则。当前固定 DPR 策略以攻击动作推进，天赋的友方定向技能、冷却和各段抗穿通过离线指令夹具验证。秘技需要战前指令入口，暂不计入。

运行 `cargo test -p star-rail-battle-core --locked --offline dan_heng` 可复验 8 项角色回归，覆盖四段伤害、暴击触发、E1/E6、减速到期、减速增益、加速随机流、天赋触发与 E2 冷却、E4 击杀后的行动值和重复结算。伤害期望值根据测试面板、每段倍率和伤害乘区独立计算。[角色测试](../../crates/battle-core/src/battle/official/dan_heng/tests.rs)
