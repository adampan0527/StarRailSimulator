# 同谐开拓者 4.7.0 固定靶场技能

采用锁定目录的 `trailblazer.harmony` 基础配置。男女源 ID 8005 和 8006 共用虚数、同谐、140 点能量和同一套战斗参数。目录以 8005 的技能与行迹 ID 保存统一配置。普攻按 6 级，战技、终结技与天赋按 10 级说明。[目录与来源锁](../m03-profiles.md#数据来源与离线重建) · [原表校验值](../../scripts/m03/source-lock.json)

| 动作 | 结算 |
| --- | --- |
| 普攻「摇摆的礼仪」 | 向单个目标造成 100% 攻击力的虚数伤害，削韧 10，恢复 20 能量和 1 个战技点。 |
| 战技「中场馈赠的雨」 | 消耗 1 个战技点。首段对指定目标造成 50% 攻击力的虚数伤害，削韧 10。随后随机弹射四次，每次相同倍率、削韧 5。每段命中回 6 能量。随波逐流（A4）使首段削韧加倍。 |
| 终结技「喧嚣的舞灯巡游」 | 消耗 140 能量，恢复 5 能量。为全队提供 30% 击破特攻与伴舞，持续至开拓者第三个后续普通回合开始。 |
| 天赋「全屏段的高空踏歌」 | 队伍使一个敌人从有韧性转为弱点击破时，开拓者回复 10 能量。剧院之帽（A6）让该次击破对存活敌人的行动再延后 30%。 |

- 伴舞将一次攻击中命中已击破目标的各段有效削韧相加，按目标和属性结算一笔超击破。首个击破段结算普通击破伤害，后续有效段计入超击破。攻击结束时目标必须存活。卫我起舞（A2）按场上至少 5、4、3、2、1 个敌人，将超击破乘以 120%、130%、140%、150%、160%。现有技能中的非弱点削韧例外仍生效。
- 超击破按出手者等级、击破特攻、有效削韧和目标的减防、抗性及击破易伤计算。80 级基值为 3767.5533，削韧以普通普攻 10 为基准。沿用引擎的每段整数削韧取整，伤害公式统一在最终值舍去小数。阮·梅的击破效率等伤害增量按来源归因，伴舞提供者获得其余贡献。日志保留实际出手者及动作。[原始超击破公式实测](https://www.reddit.com/r/HonkaiStarRail/comments/1co5sqr/calculating_understanding_super_break/) · [同次攻击的击破边界实测](https://www.reddit.com/r/HonkaiStarRail/comments/1dbadt2/)
- E1 只在第一次战技结束后返还战技点。E2 在前三个普通回合结束前提供 25% 能量恢复效率。E4 把开拓者实时击破特攻的 15% 提供给其他队友，计算基数包含开拓者自己的伴舞和其他角色增益。E6 添加两次战技弹射。E3 和 E5 由档案层解析技能等级。
- 固定打法能量就绪即施放终结技，普通回合继续使用共享的输出优先级。伴舞超击破在当次攻击的既有监听效果之后结算。多来源超击破的客户端顺序、攻击中途改变击破效率时的取值和角色退场对伴舞的影响待逐事件对照。秘技的入场击破特攻属于战前流程。

运行 `cargo test -p star-rail-battle-core --locked --offline trailblazer_harmony` 可复验 E6 段数、E2 回能、E4 击破特攻、击破首段和后续段的区别、两靶机分别归集、有限敌人击杀与固定种子逐击归因。单靶机在战技首段击破后由四次后续命中形成 10,448 点超击破。[角色回归](../../crates/battle-core/src/battle/official/trailblazer_harmony/tests.rs)
