# 流萤 4.7.0 固定靶场技能

适用于 `character.1310`，毁灭·火，能量上限 240。档案默认使用角色强化版 `novaflare`，也可选原版 `base`。表中普攻等级为 6，战技、终结技与天赋等级为 10。强化普攻和强化战技分别跟随普攻和战技等级。削韧以普通普攻为 10 的口径表示。[档案数据修订](../m03-profiles.md) · [原始数据锁](../../scripts/m03/source-lock.json)

| 动作 | 两版共同结算 |
| --- | --- |
| 普攻「指令-闪燃推进」 | 对单体造成 100% 攻击力的火伤，削韧 10，恢复 20 能量与 1 点战技点。 |
| 战技「指令-天火轰击」 | 消耗 1 点战技点和 40% 生命上限，生命最低降至 1。对单体造成 200% 攻击力的火伤，削韧 20。固定恢复 60% 能量上限（144 点），下一次行动提前 25%。 |
| 终结技「火萤Ⅳ型-完全燃烧」 | 满能量且处于普通形态时可施放，消耗 240 能量并恢复 5 基础能量。行动提前 100%，完全燃烧期间速度提高 60。独立倒计时以固定速度 70 行动，轮到倒计时即退出完全燃烧。 |
| 强化普攻「火萤Ⅳ型-底火斩击」 | 恢复 20% 生命上限，对单体造成 200% 攻击力的火伤，削韧 15。恢复 1 点战技点。 |
| 强化战技「火萤Ⅳ型-死星过载」 | 恢复 25% 生命上限，在命中前施加 2 个目标回合的火弱点。主目标承受（200% + 0.2 × 击破特攻）攻击力的火伤，削韧 30。相邻敌人各承受（100% + 0.1 × 击破特攻）攻击力的火伤，削韧 15。直接伤害倍率最多按 360% 击破特攻计算。 |
| 天赋「茧式源火中枢」 | 生命越低减伤越高，生命不高于 20% 即达到最大值 40%。完全燃烧期间维持最大减伤，效果抵抗提高 30%。开战时能量至少 120；回复至上限时清除自身可解除的负面效果。 |

强化普攻和强化战技在单次攻击内提高流萤 50% 弱点击破效率，并使该次攻击所造成的自身击破伤害提高 20%。两者的基础回能为 0；强化战技在 E0 消耗 1 点战技点。倒计时保有独立行动值且无法被队友拉条。

| 机制 | 原版 | 强化版 |
| --- | --- | --- |
| 强化战技植入目标 | 主目标 | 主目标和相邻目标 |
| A2「α模组-偏时迸发」 | 完全燃烧期间对无火弱点目标也可按 55% 比例削韧。 | 完全燃烧期间击破特攻提高 25%。强化攻击每使一个目标陷入弱点击破，倒计时延后 10%，每次完全燃烧最多触发 3 次。 |
| A4「β模组-自限装甲」 | 击破特攻达 200% / 360% 时，对已经击破的目标分别结算 35% / 50% 自源超击破。 | 对应门槛为 150% / 300%，倍率为 100% / 150%。 |
| E2「自破碎的天空坠落」 | 强化攻击触发弱点击破或击杀时获得 1 个额外回合，再完成 1 个普通回合可重新触发。 | 每个流萤普通回合开始时重新获得触发机会。 |

A6「γ模组-过载核心」使攻击力超过 1800 后每满 10 点转化 0.8% 击破特攻。攻击增益对转化值、强化战技直伤和 A4 档位的影响进入逐击归因。E1 强化战技免战技点且无视 15% 防御。E3 和 E5 随档案解析等级。E4 完全燃烧期间额外提高 50% 效果抵抗。E6 完全燃烧期间火属性抗性穿透提高 20%，强化普攻和强化战技再提高 50% 弱点击破效率。额外回合不能再次触发 E2。

固定打法优先施放就绪的终结技，其次使用战技，战技点不足时用普攻。每个目标的强化攻击按一段伤害和削韧结算。该段击破后，后续已击破命中才提供给超击破汇总。削韧效率与跨属性削韧比例合算后取整。当前模型在普通形态下按生命比例线性插值减伤，强化战技按主目标、相邻敌顺序结算，倒计时延后按新击破目标数计。这些逐事件细节及已存在火弱点时的植入续期，仍待客户端对照。秘技「Δ指令-焦土陨击」的战前下落攻击和波次开场植入留待战前入口。
