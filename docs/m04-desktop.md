# M04 · 桌面训练与回放

## 使用流程

1. 启动 Windows 桌面应用。首次启动自动创建四人训练队伍和初始配装。在「组队」打开「合成训练」，可进入独立的「训练配装」页，装备或卸下训练装备、调整训练靴速度词条，并保存和切换命名方案。
2. 从上方选择训练靶机。点击下方从左到右的四个站位，在弹窗中选择角色或设为空位。属性和命途可组合筛选。保存队伍后使用当前已保存配装开战。保持初始四人、站位、装备和双目标时，可复现 [M02 的完整战斗](m02-core.md#固定夹具的独立预期)。
3. 战斗页列出当前行动者、按当前行动条排序的单位和资源。选择普攻、战技或已充能的终结技，根据需要选择目标，再执行指令。
4. 每条已接受指令自动保存。打开「历史回放」，选择一场训练并用「定位事件」查看普攻、击破、终结技和结算等事件。未结束的战斗可以继续执行指令。
5. 将开拓者训练靴的速度副词条从 `+2.3` 改为 `+2.6`，保存并新开一场同阵容战斗。两场在各执行前两条基准指令后，开拓者的首次行动分别为 `108.342362 AV` 与 `107.991361 AV`。

训练使用随程序提供的 M02 合成数据。正式服角色档案和库存使用单独的存档。在构建 Release 前按 [M03 导入流程](m03-profiles.md#数据来源与离线重建)生成 `catalog.json`，构建出的可执行文件会内置正式服目录。已有手动导入的目录优先使用。缺少内置数据的构建仍可在「角色」或「遗器」页手动导入。到「遗器」录入库存，在「角色」搜索并打开角色卡片，设置星魂和穿戴遗器，再回到「正式服队伍」选择角色。相同数值的两件遗器独立入库，每件遗器至多有一名穿戴者。已穿戴的遗器可修改同部位的配置，卸下后可删除或改部位。正式服队伍当前支持档案和阵容编辑，正式关卡与角色战斗效果待接入。

## 接口和存档

- Tauri 命令在后台调用应用层，前端显示 Rust 核心返回的合法指令、行动顺序和单位状态。行动列表与战斗调度共用排序规则。行动顺序随当前行动条和后续指令重新计算。
- %LOCALAPPDATA% 下应用标识目录的 `training` 子目录存放 `training-profiles.sqlite` 和 `training-replays.sqlite`。配装沿用 M03 档案接口。开战时把档案冻结为战斗会话 v1，独立保存完整初始条件、版本与种子。
- `characters` 子目录保存手动导入的正式服数据包和 `profiles.sqlite`。档案 schema v2 增加遗器实例和一对一穿戴关系，v3 增加持有光锥实例及独占的装备关系。v1 和 v2 存档就地迁移，预设已有的光锥继续作为自定义光锥。四站位使用存档已有的站位字段，保存星魂、光锥和遗器穿戴在同一事务内完成。冻结配置时读取所装备的库存实例数值。
- 回放存储使用 SQLite schema v1。接受指令和更新会话在同一事务内完成。打开回放时按原有快照和指令重算，版本不兼容时显示提示。修改配装不会改写已开始的会话。

## 光锥库与遗器筛选

- 点击任一遗器槽打开库存弹窗，部位默认选中该槽，可以改为其他部位或全部部位。部位、套装、主词条和副词条可组合筛选。遗器按自身部位加入当前草稿，其他角色已穿戴的实例显示持有者并禁用。
- 「选择光锥」弹窗包含「自选光锥」和「光锥库」两个标签，均可按命途筛选。自选时先设定 S1–S5，再点击图鉴中的光锥，新选择默认使用 80 级。库中持有件的等级、突破和叠影在顶部「光锥库」维护，同名光锥各自拥有库存 ID。装备持有件后按该实例计算面板。
