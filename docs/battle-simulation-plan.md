# 编队与自动战斗模拟开发计划

## 第一阶段 · 编队和选队

- 主导航使用「编队」和「战斗模拟」。编队分为「己方」与「敌方」。己方沿用当前账号的角色、站位、配队和固定靶场 DPR。敌方可以保存多套命名编队，按站位选择敌人和等级，查看目录已提供的属性。敌方编队在本机共享。
- 「战斗模拟」从已保存的配队选择双方，列出实际成员和敌方等级。既有本地战斗记录可只读查看。当前 4.7.0 敌方目录提供部分静态面板，正式编队自动模拟需要后续的开战校验和敌方规则。
- 验收时用两套己方和两套敌方切换选队，重启后核对敌方保存内容、站位和等级。检查旧己方配队、DPR 和战斗记录仍可打开。

## 第二阶段 · 确定性搜索与单步回放

- 用现有确定性测试夹具验证自动搜索链路，为搜索结果生成同一冻结输入下的执行步骤、每步快照和事件。复用战斗核心的合法指令与结算，支持技能、目标和终结技插入的搜索。桌面入口在接入正式编队后开放。
- 战场使用上敌下己的头像，生命、能量、韧性与战技点随快照更新。右栏显示已计算的行动者、招式、目标和行动值。高亮下一条待执行行动，左侧显示此前最后一步的结算结果。结算记录从开局可展开，允许为空。
- 后台显示已评估数量和预算，支持取消。按已有行动值下界判断是否能证明最优。预算耗尽时标明已找到的最佳结果或尚未找到通关方案。
- 用小场景穷举对照最短行动值。回放前进、后退和连续播放应得到相同快照。检查同一行动推进里的自动敌方出手、追加攻击与终结技排序。重新载入本地既有回放并核对原有记录。

## 第三阶段 · 正式编队接入

- 从已保存己方阵容冻结角色面板、有效配装和技能参数。从敌方阵容解析站位、等级、基础属性、削韧和已验证的敌方行动规则，给首批支持敌人补齐逐行动验证。开战前逐成员列出缺失或不支持规则。
- 先接入一组确定性的正式队伍与敌方，验证并保存可重放的输入、规则版本、种子和指令。用修改配装与等级的回归确认既有回放仍对应原先快照。
- Windows 原生 100% 与 150% 缩放下检查选队、头像与资源条、右栏高亮、空结算记录、键盘操作和错误提示。验收结果回填路线图。

## 第四阶段 · 随机对局

- 用蒙特卡洛树搜索评估基于可观察战场状态的策略。在同一战斗窗口和搜索预算下，以独立且相同的随机种子复测候选，优先比较胜率，其次比较胜场平均行动值。
- 展示样本数、胜率、胜场平均行动值及一份可复现的回放。对照小规模可穷举的随机场景与固定策略，核对固定种子、预算和线程条件下的可重复性。
